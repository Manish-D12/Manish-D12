### 🚁 Current Project — UAV Clustering Agent

A multi-agent AI system that teaches a fleet of drones to cooperate, deciding:

- **Clustering** — which users each drone serves
- **Deployment** — where drones should be positioned
- **Resource allocation** — how bandwidth and power are shared

Trained with **PPO** (Proximal Policy Optimization) so multiple drone agents learn these decisions together.
